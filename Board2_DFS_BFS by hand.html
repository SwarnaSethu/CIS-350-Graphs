Board 2 — Roadmap

Same graph as Board 1 — Ann, Ben, Cam, Dee, Eli

  • DFS — go deep first, backtrack when stuck. Uses a Stack.
  • BFS — go wide first, one "ring" of distance at a time. Uses a Queue.
  • We'll trace both, step by step, starting from Ann, then compare the orders and talk about which real problems each one actually solves.
The example graph (same as Board 1)

1 — What is Depth-First Search?

uses a Stack

  • Go as deep as possible down one path before backtracking.
  • "Follow Ann → Ben → Ben's unvisited friend → keep going until stuck, then back up."
  • Natural fit for a Stack (LIFO) — the exact IntStack class you already built. Push where you are; when stuck, pop back to the last fork.

2 — What is Breadth-First Search?

uses a Queue

  • Go wide first — visit everyone one hop away, then everyone two hops away, and so on.
  • "Visit Ann, then all of Ann's direct friends, then all of THEIR unvisited friends."
  • Natural fit for a Queue (FIFO) — the exact IntQueue class you already built. Enqueue neighbors as you find them; always handle the oldest one next.

Which One Fits Which Real Problem?

Both visit every reachable vertex exactly once — the difference is order

DFS fits when...
"does a path exist, or find ANY path"
Solving a maze · detecting a cycle · exploring every possibility (backtracking, puzzles like Sudoku) · topological sort (e.g. ordering course prerequisites) · checking if a graph is fully connected
BFS fits when...
"find the SHORTEST / FEWEST-STEPS path"
Fewest flight layovers between two cities · "degrees of separation" on a social network (LinkedIn's 2nd/3rd connections) · web crawlers scanning a site level by level · shortest route by number of turns on a map

Check Your Understanding

 

Which traversal?

You want to know the fewest number of flight connections to get from Ann's city to Eli's city. Which traversal do you run?

DFS — dig down one route as far as possible first
BFS — explore one hop at a time, so the first time you reach Eli is guaranteed to be via the fewest hops
BFS. Because it visits in layers (1 hop, then 2 hops, then 3...), the very first time BFS reaches a vertex is always its shortest hop-count from the start. DFS could easily wander down a long path first.
