# CIS 350 — Graphs

Interactive, click-through "whiteboard" boards for the Graphs unit in CIS 350 (Data Structures). Each board is a single self-contained HTML file — open it in any browser, no setup required — and walks through one topic step by step using a left-hand rail, Next/Back buttons, and keyboard arrow keys, the same way the unit is taught live in class.

Running example used across every board: five friends on a social app — **Ann, Ben, Cam, Dee, Eli** — connected by six friendships (edges).

## Boards

| Board | Covers |
|---|---|
| [`Board1_Intro_Graph.html`](Board1_Intro_Graph.html) | What a graph is: vertices, edges, vocabulary (adjacent, degree, directed/undirected), real-world examples, and the adjacency matrix and adjacency list by hand |
| [`Board2_DFS_BFS by hand.html`](<Board2_DFS_BFS by hand.html>) | Depth-First Search and Breadth-First Search, traced by hand with a stack and a queue |
| [`Board3_RepresentingTheGraph_code.html`](Board3_RepresentingTheGraph_code.html) | Representing the graph in memory (arrays, adjacency matrix) and the full C# `Graph` class — constructor, `AddVertex`, `AddEdge`, `IndexOf`, `DFS`, `BFS` |

## How to use

Download or clone the repo, then open any board file directly in a browser. Click a step in the left rail to jump to it, or use **Next / Back** (also bound to the arrow keys, Space, and Page Up/Down) to step through in order.

## Related materials

- **Part 1 handout** — *What's a Graph?* (vocabulary, adjacency matrix, adjacency list, DFS/BFS traced by hand)
- **Part 2 handout** — *Coding DFS and BFS* (translating the by-hand process into the C# `Graph` class)

Both handouts follow the same example graph and trace order as these boards.
